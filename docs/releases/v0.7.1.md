# Nexa Platform v0.7.1

## Summary

Operations release stabilization for the internal Angular workspace.

## Highlights

- Server-backed Sales Dashboard metrics for Purchase Requests and Sales Orders.
- Dedicated role landing, loading, empty, error, retry and navigation coverage.
- Warehouse and Logistics actions remain explicit API commands with permission guards.
- Duplicate workspace artifacts are removed; generated browser output is ignored.

## Boundary

This release does not claim full Vue pixel parity. TASK-011 document routes, uploads, documents and payments are not implemented.
