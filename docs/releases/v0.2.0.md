# Nexa Platform v0.2.0

Released: 2026-07-28

## Summary

Shared frontend foundations and canonical catalog media for the internal Nexa operations application.

## Breaking changes

No intentional breaking changes.

## Added

- Durable `/overview` routing and responsive internal shell.
- Brand logo, page header, section panel, empty, loading, error, metric, status and cold-chain visual components.
- EN/ES language service and switcher with `nexa.language` persistence and storage fallback.
- Pure address, date and number utilities with focused tests.
- 50 canonical catalog assets with manifest checksums and `validate:catalog-assets`.

## Changed

- Normalized tokens, typography, motion, accessibility and Angular Material theme layers.
- Removed technical baseline messaging from the application surface.

## Fixed

- Root and unknown routes now resolve to `/overview`.

## Security

No authentication or authorization was added. No credentials or secrets are included.

## Data and assets

The API seed remains the catalog data authority. This repository contains only the 50 referenced media files; the seed SHA-256 is `c9fdb629c3996f78918081a6e7f6598ce44c8ede05a8208c7f77785367ca096b`.

## Upgrade instructions

Run `npm ci`, `npm run validate:catalog-assets`, `npm test` and `npm run build`.

## Validation

Angular unit tests, production build and catalog asset checksum validation passed on the release branch.

## Known limitations

Business workflows, API integration, authentication, persistence, deployment and visual parity certification against matched authenticated Vue captures remain outside this release.
