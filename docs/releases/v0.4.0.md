# Nexa Platform v0.4.0

## Summary

Platform internal access and secured Product Catalog release.

## Highlights

- Fixed Platform surface sign-in with identifier, password and workspace slug.
- Added session restoration, in-memory access-token handling and internal-role enforcement.
- Added protected `/ops/overview` and `/ops/product-catalog` routes with aliases.
- Added secured Catalog table, filters, sorting, pagination and detail experience.

## Security impact

Platform accepts `COMPANY_OWNER`, `SALES`, `WAREHOUSE` and `LOGISTICS`; `BUYER` is rejected. Tokens are not stored in browser storage. API remains final authorization authority.

## Breaking changes

Old shell-only route behavior is replaced by authentication-gated routes. `/overview` and `/ops/catalog` remain aliases.

## Migration impact

Configure API runtime URL and local credentials through existing runtime configuration. No package migration included.

## Validation

Unit tests, Angular build, catalog asset validation and browser scenarios are required before publication; exact results belong to final audit evidence.

## Known limitations

No full visual parity with Vue, complete Nexa migration or production deployment is claimed.
