## Summary

Production API-only adapter composition.

## Included

- Application bootstrap binds Platform IAM, catalog, sales, inventory,
  fulfillment, payments, documents and notifications ports directly to their
  HTTP clients or explicit API gateways.
- Operational route compositions bind Warehouse Operations and cross-context
  Inventory ports directly to API adapters.
- Mock implementations remain available for isolated unit/provider tests but
  are not imported by the production bootstrap or route composition.

## Architecture and boundary

- Existing ports, clients, gateways and API contracts remain unchanged.
- No endpoint, entity, state, persistence model, dependency or cross-context
  contract was introduced.
- Dispatch remains the user-facing label for canonical backend capability
  `LOGISTICS`.
- `BOM` remains `OPEN`/`DEFERRED` because no accepted role, endpoint, entity or
  lifecycle contract exists.
