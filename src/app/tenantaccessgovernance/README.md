# BC-01 — Tenant & Access Governance

Frontera frontend de IAM, administración de tenant/workspace y auditoría de seguridad. Los casos reales viven en los subcontextos técnicos `iam` y `tenantmanagement`; cada uno conserva `application`, `domain`, `infrastructure` y `presentation`. Las capas directas de este directorio son la frontera documental/compositiva y no duplican contratos.
